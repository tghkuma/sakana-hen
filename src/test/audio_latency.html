効果音の遅延テスト

ボタンを押してから鳴るまでの時間を計測します。各方式で「正解」「不正解」を交互に 5 回ずつ押して比べてください。

数値は、タップしてから再生が始まった（playing イベント / 再生位置が進み始めた）までの時間です。耳で聞いた遅れも合わせてメモしてください。

「開始位置」は play() を呼んだ時点 → 再生が始まった時点の再生位置です。左が 0 でないと頭出しできていない、右が大きいと途中から再生されています。

A. 現状の方式

pause → currentTime = 0 → play（ゲームと同じ）

-

B. 頭出しを先に済ませておく

再生が終わった時点で頭出ししておき、押したときはすぐ play（要素を 2 つ交互に使う）

-

C. B ＋ 無音をループ再生し続ける

音声出力を立ち上げたままにする。最初にこのボタンを押したときから無音のループが始まります。コントロールセンターやロック画面に再生中の表示が出るかも確認してください。

-

E. 毎回新しい要素で再生

要素を使い回さず、押すたびに new Audio() で作って再生する

-

G. 事前に作った新しい要素で再生（ゲームに組み込んだ方式）

次の再生用の要素を事前に作っておき、押したらそれで再生してすぐ次の要素を作る（要素は使い捨て）

-

F. B の方式で WAV を再生

MP3/OGG を Web Audio でデコードして WAV（無圧縮）に変換し、B と同じ方式で再生する。「準備中」と出たら少し待ってください。

-

D. Web Audio（比較用）

古い iOS では消音スイッチが ON だと鳴りません。消音スイッチを OFF にして試してください。数値は「playing」が再生命令までの時間、「再生位置」の欄がブラウザの報告する出力の遅れ（無ければ -）です。A〜C と耳で比べてください。
